## ⚡ 3-Step Process to Get Your PDF

### Step 1: Install Pandoc (One-Time Setup)

**Windows:**
- Download: https://github.com/jgm/pandoc/releases/latest
- Install the `.msi` file
- Also install MiKTeX: https://miktex.org/download

**Mac:**
```bash
brew install pandoc
brew install --cask mactex
```

**Linux:**
```bash
sudo apt-get install pandoc texlive-xetex
```

### Step 2: Run the Script

**Windows:**
- Double-click `generate-pdf.ps1`
- Or right-click → "Run with PowerShell"

**Mac/Linux:**
```bash
./generate-pdf.sh
```

### Step 3: Get Your PDF

- PDF will be created: `CRM-LWS-Complete-Documentation.pdf`
- Open and enjoy!
